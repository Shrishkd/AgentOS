# Threat model

Protect tenant data, provider credentials, approval authority, external side effects and the platform's execution budget. Trust the database, identity verifier, deployed tool implementations and operators administering their secrets. Treat browsers, model output, retrieved documents, tool results and broker deliveries as untrusted inputs. A compromised privileged worker or database administrator can affect multiple tenants. Isolating worker pools per trust domain is a deployment option for higher-risk tenants.

| Boundary and threat | Enforcement point | Acceptance test |
| --- | --- | --- |
| Client selects another tenant, guesses an ID or reuses a stale token | Validate OIDC issuer, audience, signature and expiry. Resolve active membership for the requested tenant. Scope reads, writes and event streams with RLS and composite FKs. | Tenant B receives 404 for tenant A's run and cannot subscribe, decide its approval or insert a cross-tenant FK. |
| Client elevates privileges or forges an approval | Roles are viewer (read), developer (manage agents, submit/cancel runs), approver (decide), admin (all tenant permissions). Use dedicated platform operator credentials for infrastructure. Check current roles on every command. | Developer token cannot approve. Replaying a decision with changed arguments fails. |
| Prompt injection requests unauthorized code or tools | Model output can only propose typed actions. Gateway resolves deployed implementations, checks version grants, risk, schemas and current disable flags. Tool output is bounded, labeled untrusted and escaped for display. | Malicious web content cannot add a grant, change the selected provider or execute shell code. |
| HTTP tool reaches private services or metadata endpoints | Permit HTTP(S) with approved ports and destinations. Resolve and validate every address, pin the connection to a validated address, preserve TLS hostname checks, and revalidate each redirect. Deny loopback, private, link-local, mapped and reserved addresses. Enforce independent egress filtering. | Block private IPv4/IPv6, mixed DNS answers, rebinding and redirects to metadata. |
| Read-only tool leaks production data or consumes resources | Use a separate test database, read-only role, allowlisted parameterized queries, tenant-scoped inputs, row, byte and statement-time limits. Use bounded parsers and output caps for other tools. | Reject non-registered queries and cap slow or oversized responses. |
| Flooding, excessive model charges or stuck workers | Request-size and schema limits at ingress, Redis rate limits, database quotas, finite attempts, absolute deadlines, conservative token/cost reservations and bounded worker concurrency. Fail closed on expensive submissions when the limiter is unavailable. | Concurrent submissions respect quota. Provider timeout retains an uncertain reservation. |
| Sensitive prompts or credentials appear in the dashboard, queue or logs | Store secret references in configs. Resolve credentials only in the adapter, protect connections with TLS and encrypt disks/backups. Redact sensitive fields before logging/tracing, restrict raw payload reads and audit privileged actions. | Seed a sentinel credential and assert it is absent from events, logs, errors and queue messages. |
| Forged wakeups, stale owners or duplicate external sends | Authenticate broker clients and restrict subject permissions. Treat wakeups as hints. Check DB ownership at every commit and bind remote requests to the persisted operation key. | Duplicate events and delayed workers yield one committed result for a deduplicating tool. |

Use same-origin dashboard requests, short-lived credentials and restrictive CORS. For cookie-based sessions require secure, HTTP-only cookies and CSRF protection on writes. Audit tenant, principal, action, object, outcome and request ID for registry changes, decisions and administrative access. Append security-sensitive audit events transactionally and restrict modification rights. Redaction of a trace cannot undo disclosure in an external model request. Enforce provider and egress policy before dispatch.
